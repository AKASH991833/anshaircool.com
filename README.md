# Ansh Air Cool - Business Website

Website for Ansh Air Cool, an AC sales and service business in Mumbai. Static frontend with a JSON-backed content store (`transparentdb/`) and an admin panel for managing products, services, gallery, testimonials and contact enquiries.

## Structure

- `index.html`, `gallery.html`, `styles.css`, `script.js` - customer-facing pages
- `frontend/admin/` - admin panel (dashboard, products, services, orders, contacts, settings)
- `frontend/assets/` - shared CSS/JS and images
- `transparentdb/` - JSON data store and loader

## Run locally

Serve the folder with any static file server and open `index.html`.
